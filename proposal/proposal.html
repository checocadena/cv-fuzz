What it is

CV Fuzz is a fuzz plugin whose interface is Checo Cadena's resume. Each of its four knobs shapes the sound and opens one section of the CV.

The sound is a C++ model of a fuzz pedal Checo designed and built at NYU, with NYU grant funding. The signal goes through a bias stage that can be starved like a dying battery, up to +35.7 dB of drive, an asymmetric clipper that runs at 4 times the sample rate, a DC blocker, a tone control and an output level.

The interface is the CV. Turning a knob changes the sound and flips through one section: Fuzz opens Projects, Tone opens Experience, Level opens Education and Bias opens Recognition. The tick marks around each knob are detents, one per entry. The name is a pun: in modular synthesis, CV means control voltage, the signal that moves a parameter.

How it is made. CV Fuzz is built with JUCE 8 as an Audio Unit, a VST3 and a standalone app. The interface is a web page running inside the plugin window and bound to the real C++ parameters, so automation and saved sessions work as usual. The same page runs in a browser with a Web Audio approximation of the sound, which is the online demo.

Stage: version {{VERSION}}, released on GitHub on {{RELEASED}} with installers for macOS, Windows and Linux. It is free and the source code is MIT licensed. The repository lists its own limits: the anti-aliasing filters are gentle, parameters are not smoothed yet, and the clipper is a tuned waveshaper, not a component-level model of the original pedal's circuit.

DSP

The signal path

{{SIGNAL_SVG}}

Bias models a starved transistor. It adds an offset before the drive, so anything quieter than the offset sits on one side of the clipper and the DC blocker turns it into silence: tails choke off and loud hits sputter through. At full Bias the bottom rail also drops from 0.46 to about 0.07. On a synthesized drum loop at Fuzz 60%, 39% of the audible time chokes to near-silence at half Bias and 70% at full Bias.

The clipper uses tanh on each half of the wave, flattening at +0.70 on top and -0.46 below. A symmetric clipper makes only odd harmonics. The asymmetry adds even ones, which give fuzz its thicker sound. With a pure 220 Hz sine, the even harmonics sit about 35 dB below the fundamental.

Oversampling. The clipper runs at 4 times the sample rate, between two second-order Butterworth lowpass filters at 0.45 times the original rate, to reduce aliasing.

Tone and Level. Tone crossfades between the signal and a lowpassed copy whose cutoff rises from 500 Hz to 6 kHz, a simple stand-in for a pedal's passive tone network. Level is the output gain.

Architecture. The DSP is one C++ class with no framework dependency. The interface is one HTML file compiled into the plugin, so it never needs network access. A lock-free ring buffer of 4,096 samples feeds the oscilloscope on every display refresh.

Tested with a standalone C++ harness that renders a pure sine, a synthesized plucked-string riff, a sine sweep from 80 Hz to 2 kHz and a synthesized drum loop, analyzed in Python. Next steps listed in the repository: steeper anti-aliasing, parameter smoothing, a DC blocker that follows the sample rate, a circuit-level model of the original pedal, and an RNBO version.

Setup and links

Version
{{VERSION}}, released {{RELEASED}}.
Download from {{REPO_URL}}/releases/latest
macOS
macOS 11 or later, Apple Silicon and Intel. CV-Fuzz-macOS.pkg, signed and notarized. Audio Unit, VST3 and standalone app; the installer lets you pick which.
Windows
Windows 10 or 11, 64-bit. CV-Fuzz-Windows-Setup.exe: VST3 and standalone app. The installer is not code-signed, so SmartScreen may warn: choose More info, then Run anyway.
Linux
x86-64. CV-Fuzz-Linux-x64.tar.gz, then run install.sh: VST3 in ~/.vst3, standalone as cv-fuzz. Needs WebKitGTK 4.1.
In a DAW
In Ableton Live: Settings > Plug-Ins, turn on Audio Units (Mac) and VST3, then Rescan. CV Fuzz is under Checo Cadena.
From source
./build-mac.sh on a Mac with Xcode Command Line Tools and CMake. JUCE 8.0.4 is downloaded automatically. Windows and Linux builds run on GitHub Actions.

About the artist

Checo Cadena is a New York-based singer-songwriter, sound artist and creative technologist from Monterrey, Mexico, who writes and produces records and builds the machines around them: plugins, robots, installations and software. Since 2023 Cadena has been Computer Control Engineer at Amorphic Robot Works, Chico MacMurtrie's robotic sculpture studio. Cadena holds a B.S. in Integrated Design and Media from NYU Tandon and an M.A. in Creative Media and Technology from Berklee NYC.
