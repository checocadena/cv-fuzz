Plugin

Running in
Ableton Live

A fuzz plugin whose interface is a resume. Each knob shapes the sound and opens one section of it.

Formats
AU, VST3 and standalone on macOS. VST3 and standalone on Windows and Linux.
Knobs
Fuzz, Tone, Level, Bias. Each one opens Projects, Experience, Education or Recognition.
In the DAW
All four knobs are automatable. Automating one moves it on screen.
